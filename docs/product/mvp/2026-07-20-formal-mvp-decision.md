## 2. 首个正式版本的定位

`M1` 是**邀请制私密测试版（Private Alpha）**，不是公开商业发布。

它服务于宠物离世已有一段时间、希望保存真实记忆但不希望被推动进入沉重情绪的主人。产品不承诺疗愈，不模拟宠物，不把纪念消费作为使用前提。

M1 唯一必须成立的用户结果是：

> 用户能够安全地留下至少一条真实记忆，并在之后自然找到、查看、编辑或继续补充它。

## 3. P0 闭环

```text
进入产品
→ 创建 Ta 的私密记忆空间
→ 上传照片或写下一段原话
→ 自主选择一个轻量入口继续表达，或只保存素材
→ 可选地请求 AI 整理
→ 查看、修改并确认整理结果
→ 回到记忆空间查看、编辑、删除或再留一段
```

任何一步均可暂停。已经输入或主动确认保存的原始内容不得因为用户结束流程而丢失；未确认的 AI 整理稿只能作为草稿存在，不能覆盖用户原话或进入最终记忆。

## 4. P0 功能边界

### M1 必须具备

- 轻量身份识别与用户自己的私密空间；
- 创建、查看和编辑一个 Ta 的记忆空间；
- 上传照片、填写原话，并可靠保存原始内容；
- 从日常、相遇、关系或照片开始的记录入口；
- 单题、可跳过、可暂停、可切换至更轻问题的记录过程；
- 记忆片段列表与详情页，支持持续回看；
- 原话与 AI 整理稿并列展示，用户可编辑、拒绝或确认整理稿；
- 内容删除与数据导出入口；
- 默认私密的可理解说明与可操作控制项。

### M1 明确不做

- 社区、动态流、公开内容或默认分享；
- 宠物拟人聊天、模拟已离世宠物人格；
- 语音记录、多人协作、家庭空间；
- 主动提醒、打卡、连续使用激励；
- 纪念品、殡葬服务、广告或情绪触发式付费；
- AI 生图、视频、纪念卡片等创作能力；
- “帮助释怀”“治愈哀伤”等治疗性表达或功能承诺。

## 5. 最小信息架构

```text
入口 / 我的空间
├─ Ta 的记忆空间列表
└─ 单个记忆空间
   ├─ 最近留下（可回看）
   ├─ 新留一段
   │  ├─ 上传或只保存照片
   │  ├─ 日常 / 相遇 / 关系 / 照片入口
   │  ├─ 原话记录与安全退出
   │  └─ 可选 AI 整理与用户确认
   ├─ 记忆片段详情
   └─ 空间设置：名称、封面、导出、删除、隐私说明
```

“查看已有记忆”是完整使用，不得被强制导向继续记录；“只上传照片”也是完整行为，不得强制回答问题。

## 6. 最小数据模型

| 实体 | 责任 |
|---|---|
| 用户 | 身份、账号控制与数据请求主体 |
| 记忆空间 | 对应一只 Ta；承载默认私密边界与全部记忆 |
| 原始素材 | 用户上传的照片、用户写下的原话；不可被 AI 覆盖 |
| 记录草稿 | 当前未完成的记录与用户可恢复的表达；每个空间最多一条进行中的记录草稿 |
| 记忆片段 | 用户确认要保留的真实内容；可关联一个或多个原始素材 |
| AI 整理稿 | 基于指定原始内容生成的可编辑候选文本；必须保留来源与确认状态 |
| 用户授权 | AI 处理、提醒、分享等可撤回授权；M1 默认只需 AI 处理授权 |

## 7. 隐私与数据实施底线

正式开发前必须将以下内容落到可实现、可解释的设计中：

- 所有空间、照片与文字默认仅创建者可见；
- 上传前明确说明照片与文本会被存储在哪里、何时会被发送给 AI；
- AI 处理必须基于用户当次明确选择，且不用于模型训练或人工查看，除非另有清晰、独立的授权；
- 用户可从设置中删除单条内容、整个空间，并能请求导出自己的内容；
- 删除、导出、账户注销和草稿保留规则必须在上线前明确；
- 实际发布地区、云存储、AI 服务商与数据流确定后，单独完成适用的隐私、个人信息与平台要求核对。

## 8. AI 实施契约

AI 是可选的整理工具，不是产品人格。每次调用必须遵守：

1. 输入仅包含用户允许用于本次整理的原始素材；
2. 输出只能重组、压缩和润色已表达的事实；信息不足时保留原话或标记待补充；
3. 不推断 Ta 的想法，不评价用户，不给出心理治疗或道德判断；
4. 面对用户主动表达的沉重情绪，只承认感受并提供继续、保存、换轻入口或暂停；
5. 输出永远是草稿，必须可编辑、拒绝和删除；
6. 每个版本在上线前都要用“编造事实、放大愧疚、拟人对话、强行推进情绪”等反例测试。

## 9. 私密测试版的成功判断

不以营收或下载量作为 M1 的发布门槛。邀请制测试应关注：

- 用户是否能不依赖解释地理解产品是什么；
- 用户是否能完成一次保存，并在之后找到该内容；
- 用户在关键步骤是否感到被催促、被审问或不信任；
- AI 整理是否被用户保留、编辑或拒绝，拒绝原因是什么；
- 用户是否愿意再次回来补充，而非被提醒驱动；
- 隐私、删除、退出和恢复草稿是否可理解、可用。

## 10. 商业化边界与后续方向

M1 不收取情绪表达过程中的费用。未来若验证出长期价值，商业化可以围绕用户主动需要的长期保存、容量、导出整理与可选纪念创作展开。

无论何时，都不得在用户表达悲伤、愧疚或准备退出时以焦虑、倒计时、纪念义务或失去记忆为理由促销。

## 11. 已确认的工程路线

正式 MVP 采用微信小程序优先，客户端为 `uni-app + Vue 3 + HBuilderX`，后端为腾讯云 CloudBase。工程目录、环境隔离、云函数边界、隐私媒体处理和 AI 调用约束见 [微信小程序工程决策](../technical/2026-07-20-wechat-miniapp-engineering-decision.md)。

M0 工程骨架、设计系统规格、实施计划与开工前一致性复核已经完成。正式实施仍需用户明确授权；不得因为 M1 长期范围已经确认，就把 CloudBase、真实 AI、云端照片或导出提前加入 M0。
