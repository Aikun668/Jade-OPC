# M0 设计原型与视觉基准实施计划

> **状态：13 张标准页面图与视觉基准阶段已完成；后续 Task 2 工程规格也已于 2026-07-24 完成确认，本文件继续作为历史产出计划。**
>
> 本计划只建立用于设计决策、逐页截图和视觉验收的独立原型，不创建或替代正式 uni-app 小程序。正式产品实现仍遵循 `2026-07-23-m0-engineering-skeleton-implementation-plan.md`。
>
> 本文件中的已勾选步骤只表示 React 设计原型与视觉基准在当时已经产出，不表示正式 uni-app 小程序的实施步骤已经执行；正式工程进度只看工程骨架实施计划中的 71 个复选框。

**目标：** 以用户最终确认的空间首页生成图为 `M0 视觉母版 v0.1`，结合共享设计令牌和组件的移动端设计原型，输出 13 张标准页面图，为后续无视觉能力的 Builder 提供稳定视觉真源。

**架构：** 原型使用 Product Design 的移动端模板，应用视觉只写在原型允许修改的入口文件中，设备外壳与运行时保持不变。13 个页面共享令牌、导航、按钮、列表、草稿、表单、弹窗、照片与状态组件，通过原型内部路由切换，不接入持久化、CloudBase 或真实 AI。

**技术栈：** Product Design mobile-app 模板、React、TypeScript、Vite、CSS、Playwright 截图（获得用户许可后）。

## 全局约束

- 原型目录固定为 `apps/pet-memory-design-prototype`。
- 正式小程序目录 `apps/pet-memory-miniapp` 在本计划中不得创建或修改。
- 视觉母版固定引用 `docs/product/assets/2026-07-23-space-home-visual-master-v0.1.png`。
- 最初设计目标约为 `390 × 844` 的应用内容区域；实际 Product Design iPhone 运行时为 `393 × 852 CSS px`，13 张正式基准与后续工程测量统一采用实际运行时坐标。设备外壳不属于应用视觉规格。
- 视觉语言保持“安静的私人档案”：暖象牙白、深灰褐文字、低饱和橄榄色、大量留白、轻分隔线。
- 页面背景不得使用全局纸纹；只有草稿提示允许局部胶带和轻微撕纸感。
- 系统中文字体，不引入自定义字体或新的品牌字体。
- 不使用亮色渐变、玻璃拟态、重阴影、999px 药丸按钮、卡片套卡片、AI 人格形象或社交元素。
- 所有页面必须复用共享令牌和组件；不得为单页创造新的颜色、字号、圆角或阴影。
- 本阶段先产出 13 张标准页面图；额外状态图和组件施工图在标准页面通过后单独讨论。
- 空间首页以最终确认图片为唯一视觉真源。其胶带纸张、按钮摆放和局部比例不得直接照抄浏览器原型 CSS；后续 Task 2 已根据最终图片重新推导可实现的结构、样式与验收边界。
- 其余 12 张标准页面图来自浏览器原型，可以作为未来 Task 2 的直接视觉输入；原型代码仍只作为辅助参考，不自动成为正式产品代码。
- 未经用户明确要求，不创建 Git 提交、不推送、不部署。
