# M0 页面视觉基准

## 用途

本目录保存 M0 设计原型的 13 张标准页面图，用于：

- 用户评估整体页面方向；
- 后续讨论 Task 2 工程规格的颗粒度；
- 为无视觉能力的 Builder 提供逐页视觉真源；
- 正式小程序实现后的视觉对照。

其中 12 张图片来自同一个可运行设计原型。空间首页 `04-space-home.png` 是用户最终确认的独立生成图，用来覆盖原型中未达到要求的胶带纸张效果和按钮布局。

## 生成基线

- 视觉母版：`../2026-07-23-space-home-visual-master-v0.1.png`，内容与 `04-space-home.png` 完全一致
- 设计原型：`../../../../apps/pet-memory-design-prototype`
- 原型视口：iPhone 设备屏幕，CSS 尺寸 `393 × 852`
- 截图密度：`devicePixelRatio = 1`
- 原型截图文件像素：`394 × 852`；宽度多出的 1px 来自设备屏幕边缘取整
- 空间首页最终图像素：`853 × 1844`，作为独立高分辨率视觉基准
- 生成日期：2026-07-24
- 页面背景：纯色暖象牙白
- 标准数据：团团完整样本

设备状态栏和底部安全区由 Product Design 移动端原型运行时提供，用于呈现真实可用区域；它们不是正式小程序需要复制的应用组件。

## 空间首页特殊规则

- `04-space-home.png` 与仓库视觉母版是空间首页的唯一视觉真源。
- 草稿纸的手撕边缘、纸面纹理、胶带质感、“继续写”位置以及主按钮布局，以该图片为准。
- 浏览器原型中的空间首页 CSS 只保留交互模拟价值，不作为这些细节的实现答案。
- Task 2 已经根据最终图片形成可执行的结构、样式、组件边界与验收规则；正式实现不得直接复制当前原型 CSS。
- 其余 12 张页面图可以直接作为工程 Task 2 的视觉输入。

## 与 Task 2 工程规格的关系

本目录仍只保存 13 个标准页面状态，不为所有动态状态增加截图基准。以下内容已经由 [M0 设计系统工程执行规格](../../specs/2026-07-24-m0-design-system-engineering-spec.md) 定义：

- 按钮、输入、弹窗和底部面板的完整状态矩阵；
- 草稿冲突、保存失败、照片失效和 AI 失败的行为与视觉边界；
- 组件尺寸、页面装配和照片、草稿材质施工合同；
- 基准归一化、允许误差、截图责任、真机检查和 P0–P3 阻断规则。

没有独立视觉基准图的动态状态通过组件测试、运行时测量、自动截图或人工检查记录验收，不得伪造额外基准图片。
