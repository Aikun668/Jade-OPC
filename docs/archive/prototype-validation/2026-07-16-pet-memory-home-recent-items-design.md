# 记忆空间首页：最近留下区域设计

## 目的

让用户在保存一段记忆后，能在记忆空间首页自然找到并回看已留下的内容；查看本身即为完整使用，不把用户推入补充或继续访谈。

## 位置与状态

“最近留下”位于记忆空间首页主动作“再留一段”的下方。只有当前浏览器会话存在已保存记忆时显示；无记忆时保持现有安静留白。

## 展示形式

每条记忆使用一条纵向堆叠的横向摘要，而不是横滑相册或大卡片。

- 有照片的记忆：左侧为小型照片缩略图；右侧为标题和一行摘要。
- 无照片的记忆：不显示虚构图片，文字从左侧起始。
- 标题使用 16px；摘要使用 13px，单行截断。
- 该区域只读展示；首版不新增编辑、删除、分享或完成度提示。

## 交互与边界

- 点击整条摘要可打开该记忆的查看状态；首版可先用轻量选中反馈代表进入查看。
- 用户保存新的记忆后，已有条目仍保留，并按保存时间倒序展示。
- 仅保留当前浏览器会话中的临时数据；不新增上传、远程存储或提醒。
- 不出现“完善”“完成”“继续写”等造成压力的文案。

## 验收

1. 保存两段记忆后，首页显示“最近留下”及两条横向摘要。
2. 第一条若有关联照片，则展示其缩略图；纯文字条目不显示占位图。
3. 在无已保存记忆时，区域完全隐藏。
4. 新建记忆后，既有条目不被清空。
