## 原型边界

- 原型用于视觉选择、页面截图、共享组件验证和后续工程规格反推。
- 原型不使用正式小程序运行时，不实现持久化、CloudBase、真实 AI 或真实相册。
- 原型代码不是正式产品代码，正式实现不得直接复制未经工程审查的模拟数据和交互逻辑。
- 空间首页的胶带纸张效果、按钮摆放和局部比例不得直接参考当前原型 CSS；未来工程 Task 2 必须根据最终确认图片重新推导。
- 除空间首页外，其余 12 张标准页面图均来自原型，可直接作为未来工程 Task 2 的视觉参考。
